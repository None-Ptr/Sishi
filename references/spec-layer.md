# 特化层格式

一个场景 = 一个目录，含四个**可选**维度文件（知识点边界是共享约束，其余三个分别对应三个 agent）。

```
特化层/
└── 初三数学/                    # 场景名 = 命中检测的索引键
    ├── 知识点边界.md            # 共享约束（可选）
    ├── idea视角.md              # Idea agent 蒸馏（可选）
    ├── 出题视角.md              # 出题 agent 蒸馏（可选）
    └── 学生视角.md              # 做题 agent 蒸馏（可选）
```

## 每个维度文件的 frontmatter

```yaml
---
场景: 初三数学
维度: 知识点边界 | idea视角 | 出题视角 | 学生视角
来源: 教材/大纲/经典好题/真题/错题
更新时间: 2026-10-11
---
```

## 各维度内容要点

### 知识点边界.md（共享约束，不归属任一 agent）
- 在界内清单：可考察的知识点。
- 超纲红线：明确不可用的知识点/方法。
- 认知层次上限：该群体最多考到哪一层（如"只到应用，不考创造"）。

### idea视角.md（Idea agent 蒸馏）
- 好题眼审美：该场景"什么点子算好"（优雅 / 反直觉 / 思维含量）。
- 灵感来源：经典题眼/思想清单，可作变式的母本。
- 创新禁区：该场景不能接受的"为新而新"。

### 出题视角.md（出题 agent 蒸馏）
- 落地手艺：题干设计、数据范围设定、边界条件处理。
- 题型取舍：构造/交互/计数等题型在该场景的适用性。
- 难度梯度：基础/进阶/挑战各占比。
- 表达 DNA：题干风格、样例设计惯例。

### 学生视角.md（做题 agent 蒸馏）
- 典型水平分布：不同水平学生能做对什么。
- 常见误解清单：高频错误认知、惯性思维。
- 易卡点：哪些步骤/概念学生最容易卡住。
- 启发敏感点：哪些"点破"最能让学生有收获。

## 使用规则

- 出题时按场景命中检测加载对应目录，各 agent 加载各自维度 + 共享的"知识点边界"。
- 缺某个维度文件 → 该维度走通用兜底 + 诚实标注。
- 用户补材料 → 只更新对应维度文件，不重蒸馏整个场景。
