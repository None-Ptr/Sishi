# 出题引擎

## 输入契约

用户给模糊需求（可能只有一句话），司试**诊断补齐**后出题，不全字段逼问。

诊断补齐流程：
1. 从需求中提取已知信息。
2. 用蒸馏框架推断缺失字段：人群、知识点、认知层次、题型、难度、题量、用途。
3. 生成"假设清单"（少而关键，只列真正影响质量的字段），让用户一次性确认或修改。
4. 用户不回复 → 按假设直接出题。**以下三类必须先问后写**（把选项摆给用户，不得选定一种解读直接交付）：
   - "给谁出"完全无头绪；
   - **需求含多义关键词，且不同解读会产出完全不同的题**（例："生成函数"在算法语境 = 母函数，字面语境 = 构造一个函数；前者对初中生超纲，后者可做）；
   - **需求内部矛盾**（如"初中生 + 母函数"）且用户未说明如何取舍。
   追问时给出方向选项（改人群 / 改考点 / 换解读）。**不得因为某种解读"能做出来"就替用户选定它**——那属于变相降低门槛凑达标：不伪造门槛结论，而是重定义目标让门槛可过。事后披露不能替代事前确认。

## 六步元流程（通用底座）

> 三 agent 协同：Idea agent 发散题眼（②）；出题 agent 主导六步；做题 agent 在"验证型"步骤（③④⑥）盲做 + 报告行为，由出题 agent 对账判定。

| 步 | 名称 | 谁做 | 关键产出 |
|---|---|---|---|
| ① | 锚定考察目标 | 出题 agent | 考什么知识点 + 什么认知层次（记忆→理解→应用→分析→评价→创造） |
| ② | 设计题眼 | Idea agent 发散 + 出题 agent 收敛 | 一个核心思维跃迁点（题目的"魂"） |
| ③ | 造梯子 | 出题 agent + 做题 agent | 子问题/选项/数据范围分层，验证梯度真能区分水平 |
| ④ | 埋陷阱 | 出题 agent + 做题 agent | 针对常见误解设干扰，验证陷阱真能诱导 |
| ⑤ | 反向自检 | 出题 agent（做题 agent 轻量辅助） | 题设充分、答案唯一、无歧义、不超纲 |
| ⑥ | 启发性评估 | 出题 agent + 做题 agent | 做完是否带走可迁移的东西 |

### 各步判定标准（质量命根子）

**① 锚定考察目标**
- 做什么：锁定"考哪个知识点 + 哪个认知层次"。
- 认知层次（Bloom 六层）：记忆 → 理解 → 应用 → 分析 → 评价 → 创造。
- 判负：目标含糊（只说"考 DP"却没落到具体子能力）；目标与人群错配（给低水平人群出"创造层"）；目标超纲（考察点在知识点边界外）。
- **判负出口（三分支）**：
  1. 判负源于 **agent 推断错误** → 修正推断，重新锚定；
  2. 判负源于**用户需求本身**（如明确要求超纲内容）→ 走输入契约的硬歧义追问，把取舍交给用户；用户明确选择接受超纲 → 照常出题，但自检报告**必须列出**因此未达标的门槛项及风险，不得静默放行；
  3. 判负源于**多义解读**（一种解读超纲、另一种可做）→ 属硬歧义，先问后写；**不得默认选可做的那种**。

**② 设计题眼**
- 产出方式：由 Idea agent 发散候选（见 `references/creativity.md`），出题 agent 用下面的交接判据收敛。
- **交接判据**：候选必须**跨 ≥3 种载体**（`creativity.md` 载体轮换硬规则）。不满足 → 本轮发散判无效，出题 agent 退回重发散，不自行接手补候选。
- **收敛顺序**：按"题眼强度降序"逐个过经典度判负，取**第一个通过者**落地；不要因为候选 A 看着顺眼就跳过判负。
- **重发散上限 2 轮**（含首发散，即最多 3 轮发散）。达到上限仍全部命中经典度判负 → **如实告知用户"该需求下只能出经典复刻题"**，交用户决定是否接受；**严禁虚报题眼绕过判负**，也不许降低判负标准。
- 有题眼：存在一个必须主动想到的关键转折/视角切换/不变量/等价转化，跨过它才豁然开朗。
- 设计自检法：问自己"这题如果套公式/模板就能做，它额外考的是什么思维？"——答不出额外思维 = 无题眼。
- 题眼三档：
  - 无题眼：知识点平铺，套公式即得（判负，返工）。
  - 有题眼：单一转折，需主动想到。
  - 强题眼：转折 + 反直觉 + 可迁移（做完能带走方法）。
- **经典度判负（母本可识别性）**——强题眼不得评在"可迁移"上就结束，必须额外过这一关：
  - 测试（三条依次问）：
    1. **整题同构**：是否存在一道公开知名的母本题，**换掉题面包装后，学生的解法框架一字不改就能用**？（"换个皮就是那道题"）
    2. **距离**：从母本到本题的变式路径 **≤2 步**（换数据/换规模/加约束各算一步）。
    3. **豁免**：若两题差异**发生在载体或骨架本身**（老技术落到新载体、新骨架换新载体），则**不判经典复刻**——这正是 `creativity.md` 载体轮换与骨架置换的产物，不应被自己规定的动作判负。
  - 三条**同时成立**才判"经典复刻"：不得评强题眼，须退回 Idea agent 换载体或换骨架重发散。
  - **防滥用**：必须指名**具体题名**，"感觉像经典题"不成立；说不出母本 = 通过。第 1 条（整题同构）是主闸门，2、3 条只用于收紧或豁免，**不得跳过第 1 条单独用"≤2 步"判负**——否则会把"新技术用在新载体"误杀。
  - 注意这是**改道不是降档**：目的是逼出陌生题，不是抬高标准。若候选池已全部命中判负，如实告知"此需求下只能出经典复刻题"，交由用户决定是否接受——不要为了绕过它而虚报题眼。

**③ 造梯子**（做题 agent 轻量介入）
- 做什么：设计分层——子问题递进 / 数据范围递进 / 选项难度递进。
- 梯度三档：基础（验证基本操作）/ 进阶（验证理解）/ 挑战（验证迁移与创造）。
- 做题 agent 介入：按 `references/student-agent.md` 轻量模式，让"中等生"盲做基础子任务并报告行为；出题 agent 对账"中等生是否真做出基础、尖子生是否被挑战区分"。
- 判负：梯度塌缩（各部分一个难度、无区分）；梯度断裂（基础太难，中等生做不出基础）。

**④ 埋陷阱**（做题 agent 轻量介入）
- 做什么：针对"高频误解/惯性思维"设干扰项或易错点。
- 陷阱来源：学生视角特化层的"常见误解清单"（无特化层用通用推断并标注）。
- 做题 agent 介入：轻量模式让"易错学生"盲做并报告行为；出题 agent 对账"其行为是否真落入设计好的陷阱"。
- 判负：无诱导性（正确的人不会选错、易错的人也不会掉进去）；有争议（正确理解下仍有歧义——这是坏题，不是好陷阱）。
- **陷阱类型判负（粗心陷阱 ≠ 思维陷阱）**：出题 agent 必须先判定陷阱属于哪一类——
  - **思维陷阱**（有效）：学生的失败源于**心智模型错误**，即他即使把题面读得完全正确、注意到所有条件，仍然会错（因为他的默认认知是错的）。这是好陷阱。
  - **粗心陷阱**（判负）：学生的失败仅仅源于**漏看题面某条信息**（如"没注意到 `a_i` 可以为负"）。题面本应写清楚，让学生因为没读仔细而错，考的是注意力而非思维——**无效且不公平**。
  - 判别方法：看做题 agent 的失败报告里，**他是否明确表示"我读完了所有条件"**。若他说"我知道条件但默认它不成立"，是思维陷阱；若他说"我没注意到那条"，是粗心陷阱 → 判负重设。
  - **注意**：某些思维陷阱确实需要题面**显式声明**某个条件（如"元素可为负"），否则陷阱退化为粗心陷阱。此时正确做法是**把条件写进题面**，让陷阱回到"注意到了但仍然想错"的高度——**而不是把条件藏起来，靠粗心取胜**。

**⑤ 反向自检**（硬指标，逐条对勾）
- 题设充分：不补充隐含假设也能唯一作答。
- 答案唯一：无多解歧义。
- 无超纲：用到的知识点都在该场景边界内（有特化层用其边界，无则用通用推断并标注）。
- 表述无歧义：尤其"至少/至多/恰好"等逻辑词、指代、单位。
- 约束自洽：数据范围、边界条件、前提不矛盾。
- 样例有效：样例能帮理解题意，且样例答案正确。

**⑥ 启发性评估**（做题 agent 完整介入）
- 三问：做完是否理解了某个"为什么"（而非只记住"怎么做"）？能否迁移到同类但非原题的问题？是否暴露/纠正了一个常见误解？
- 做题 agent 介入：按 `references/student-agent.md` 完整模式，让典型学生盲做完整题并报告卡点；出题 agent 对账"是否卡一下才想通"。
- 分级：弱启发（只纠正一个具体错误）/ 中启发（理解某个"为什么"，可迁移同类题）/ 强启发（暴露普遍误解，或给了可复用的思想方法）。

## 输出契约

交付五件套：
1. **题目**：题干 + 设问 + 约束。
2. **答案**：明确、唯一。
3. **题解**（核心，承载启发性）：点破题眼 + 给出可迁移方法，不是套公式过程。
4. **自检报告**：考什么 / 难度 / 陷阱点 / 区分度 / 启发性评估，并诚实标注是否用了通用兜底。
5. **深挖失败记录**（本模板特有的第五项）：记录出题过程中**尝试过但证伪/放弃的方向**（例："原计划做格上 Möbius 反演闭式，k=2 时系数无法统一，弃用"）。
   - 健康：放弃某条路线但**保住了难度与严谨性**（自检全过、陷阱仍有效）→ 如实写出，这是原创性的正面信号。
   - 不健康：放弃后**把题做水**（降低难度、放宽严谨性、删掉已设计的陷阱）→ 判负返工。
   - 一题无失败记录**不加分**：立刻找到漂亮闭式往往说明只是复刻了熟悉结构，如实标注"无深挖失败，一次成型"。

## 质量闭环

- 出题 = 生成 → 评估 → 迭代修订。
- 评估 = 出题 agent 硬指标自评 + 做题 agent 盲做行为报告（由出题 agent 对账）。

### 收敛退出条件（达标判定）

**硬门槛（5 项全过才算达标，缺一即修订）**

| # | 门槛 | 判定 |
|---|---|---|
| G1 | 题眼达标 | 非"无题眼"，且通过经典度判负（未判经典复刻） |
| G2 | 反向自检 6 条 | 全过。**但主观项（题设充分/无歧义/约束自洽）必须有盲做行为证据背书**——solver 报告的歧义与自检结论冲突时，**以 solver 为准** |
| G3 | 梯子未塌缩未断裂 | 做题 agent 行为证实梯度可分 |
| G4 | 陷阱有效 | 至少一个陷阱被盲做行为实证命中（非自评臆测） |
| G5 | 启发性 | 六问至少答"是"两项 |

- **达标即停**，不因"还能更好"而继续打磨。
- **不达标 → 修订**，每轮只针对**被指名的具体缺陷**（如"G4 陷阱未被命中：易错学生绕过了 T2"），禁止"换个说法重来"式空转。
- **修订上限 2 轮**（即最多生成 3 版）。用满仍不达标 → **停止并如实交付当前版本 + 明确列出未达标项及其风险**，交用户判断。**不许降低门槛换取"达标"**，也不许隐瞒未达标项。
- 注意 G4 依赖做题 agent 的行为证据；若环境不支持独立 subagent（`student-agent.md` §物理隔离），G4 降级为自评并**必须在自检报告标注"陷阱有效性未获独立行为证据"**。
