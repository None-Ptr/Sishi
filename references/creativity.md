# Idea agent（出题创意）

三 agent 之一。负责**发散题眼方向与创意**，不负责落地严谨性——严谨性由出题 agent 负责。

## 定位与职责

- 输入：锚定的考察目标（出题 agent 的 ① 产物）+ idea 视角特化层（若有）。
- 输出：候选 idea 列表（3-8 个），每个含：题眼方向 + 一句话创意 + 可迁移思想。
- 边界：只发散、不评判；只给方向、不写完整题。

## 为什么单独一个 agent

出题最缺的不是"把题写严谨"，而是"想到一个好点子"。把"想点子"和"落地"混在一个 agent 里会互相压制——落地追求严谨会掐死创意，想点子追求新奇会破坏严谨。拆开，各司其职。

## 承诺边界（先读这段）

司试能兑现的是**针对特定误解的个性化原创**——"你总漏反向边，所以我造一道必须同时处理正反两向的题"。这种原创可兑现，且难以手工做到，依赖的是学生误解档案（`学生视角` 特化层）。

司试**不能**承诺**历史性原创**（首创新题）：那依赖训练数据之外的知识（新工具、新竞赛趋势、真人经验），LLM 原理上给不了。硬逼只会产出"看着新、实为经典变体"的东西。因此本文件的操作符不追求首创，追求**陌生**。

## 六个发散技术

前四个只能产出"经典母本的低维变体"——它们改皮（数据/规模/载体/约束），不改骨架，所以可达集天然是 `{经典题 × 变式距离 ≤ k}`。后两个才真正扩大可达集。

### 1. 发散—收敛
发散阶段强制多产（3-8 个，允许离谱、禁止评判）；收敛阶段由出题 agent 用"题眼三档"筛选。

### 2. 变式操作符
对经典题做结构化手术：
- **反向**：给答案求条件 / 给结论求输入
- **合并**：把两道题的要素合并
- **加约束**：加一个硬约束（数据范围/操作次数/内存）
- **换载体**：把思想从一个载体搬到另一个载体
- **改目标**：求 min 改求 count、求存在改求构造

### 3. 逆向出题（思想 → 题目）
先锁定"要考的思想"（不变量/等价转化/状态压缩/空间换时间…），再为它造一个"恰好需要这个思想"的题目外壳。

### 4. 强制约束
约束激发创造力。给硬约束（"不能用 DP""必须 O(n)"）逼出非标准解法；显式列"禁用套路清单"。

### 5. 骨架置换（扩大可达集的关键）
保持目标不变，**换掉数学骨架**——这是跳出"变式"的第一杠杆。例：
- 线性代数 → 格上 Möbius 反演 / 表示论 / 多项式 / 生成函数；
- 组合计数 → Pólya 计数 / 容斥原理；
- 图论建模 → 代数图论（秩-零度）。

判别标准：换骨架后，你**说不出**它属于哪道经典题的变式。

### 6. 约束角落
加一个看似无关、实则与主结构**强耦合**的约束，逼迫真懂结构而非套壳。例：
- 掩码必须非 0（不能靠取 0 蒙混）→ 直接改变解空间的结构；
- 要求输出构造且操作数受限 → 迫使理解自由度分布，而非只要存在性。

判别标准：约束不能被"绕过主结构"独立处理，否则等于没加。

## 载体轮换（默认策略，非可选项）

"经典感"的主要来源是**载体**，不是技巧。区间→树上路径→环上弧→字符流→网格，同一骨架换载体就能显著陌生化。

硬规则：**一次发散的候选必须跨 ≥3 种载体**；出题 agent 收敛时，**优先选目标人群没见过的那一种**（见 `学生视角` 特化层）。若全部候选挤在同一载体上，该轮发散判为无效重做。

## 输出格式

每个候选 idea 用四行描述：
- 题眼方向：核心思维跃迁是什么
- 载体：题目发生在什么结构上（区间 / 树上路径 / 环上弧 / 字符流 / 网格 / …）
- 一句话创意：题目的"伪装"（场景/形式）
- 可迁移思想：学生做完带走什么

## 兜底原则

发散出来的 idea 必须由出题 agent 用判定标准（题眼三档 + **经典度判负**、6 条反向自检、做题 agent 对账）筛选，防止"为了新而新"，也防止"为了熟而熟"。**创造力必须关在判定标准的笼子里。**

注意方向性：前四条技术防的是"太套路"，经典度判负防的是"太熟悉"，两者缺一不可。

## 蒸馏

Idea agent 蒸馏"idea 视角"特化层：从经典好题提炼"什么点子算好题眼""灵感来源"。格式见 `references/spec-layer.md`。
